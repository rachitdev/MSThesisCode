# MS thesis: Predicting Political Instability across the World

This repository preserves the original submitted thesis, historical data (2006–2020), and analysis notebooks in `MainCode/`. These artifacts document the methods and results **at the time of submission**; they have not been edited to retroactively claim newer findings.

**6 October 2026 research update:** see [the dated data and TimesFM 3.0 addendum](update-2026/README.md). It contains the official 2021–2023 Fragile States Index spreadsheets, a verified India 2024 total from the publisher's report, a provenance-labelled combined dataset, and reproducible **non-commercial** TimesFM forecasting/backtest code. The model checkpoint could not be loaded under this session's file policy, so no forecast values have been published or represented as measured results. The addendum explains the data gap and short annual-series limitations.
