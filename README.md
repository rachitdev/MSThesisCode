# MS thesis: Predicting Political Instability across the World

This repository preserves the original submitted thesis, historical data (2006–2020), and analysis notebooks in `MainCode/`. These artifacts document the methods and results **at the time of submission**; they have not been edited to retroactively claim newer findings.

**6 October 2026 research update:** see [the dated methods and data addendum](update-2026/README.md) and [the generated India projections report](update-2026/results/prophet_report.md). Official 2021–2023 Fragile States Index spreadsheets and the verified India 2024 Total feed an updated version of the thesis's Prophet method, with 2025–2029 Total projections, 2024–2029 indicator estimates and historical backtests. These are **Prophet model estimates, not published FSI observations or predictions of riots**. The separate non-commercial TimesFM 3.0 experiment remains unexecuted because its checkpoint cache write was blocked.
